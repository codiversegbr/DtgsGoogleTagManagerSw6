<h1 align="center">Google Tag Manager + GA4 + Measurement Protocol + Ads + Remarketing</h1>

<p align="center"><strong>by codiverse</strong>

<h2>Highlights</h2>
✅ Complete GA4 Enhanced Ecommerce DataLayer – all relevant shop events are automatically recorded in accordance with industry standards.<br/>
✅ Google Consent Mode V2 & GDPR-compliant – integrated cookie consent management, including compatibility with many third-party providersServer-side tracking via the Google <br/>
✅ Measurement Protocol – reliable purchase tracking even with ad blockers and without data loss.<br/>
✅ No programming knowledge required – full configuration via the Shopware backend for each sales channel.<br/>
✅ Custom tracking services – manage any third-party scripts (Meta, Pinterest, TikTok, etc.) with your own cookie consent.br/>

<h2>Features</h2>
👍 Integration of the Google Tag Manager container (GTM ID) via configuration (multiple container IDs possible).<br/>
👍 Complete GA4 Enhanced E-commerce Data Layer.<br/>
👍 Google Consent Mode V2 (Basic & Advanced).<br/>
👍 Prepared for GDPR cookie consent management.<br/>
👍 Server-side tracking via the Google Measurement Protocol (GA4).<br/>
👍 Compatibility with Usercentrics, CookieFirst, ACRIS and Shopware Cookie Consent.<br/>
👍 Separate control of analytics and marketing cookies (ad_* flags via a separate marketing cookie).<br/>
👍 Google remarketing parameters including AdWords Merchant ID.<br/>
👍 Enhanced conversions at checkout (optionally with data hashing).<br/>
👍 Selection of the price type passed (gross/net) and display of the original price for discounted items.<br/>
👍 Transfer of category names and, optionally, the database IDs of the products.<br/>
👍 Extendable via service decorator (Extendable via custom apps)<br/>
👍 Delayed/consent-dependent loading of the main GTM script (gtm.js), optionally with a custom GTM.js URL.<br/>
👍 ‘DataLayer only’ mode (remove container code) for custom container setups.<br/>
👍 Multilingual, configurable per sales channel, including developer logging for debugging.
